# 独立数据库初始化：空闲资源验证（2026-09-13）

## 改动与启动契约

基线为上一轮按角色加载优化后的 `41f9603c2`（镜像后端代码对应 `c23b0d3f9`），候选为 `48abd36c7`。本轮只将一次性数据库初始化移出常驻 cluster 主进程，不改变 HTTP/gRPC 服务拆分、PM2、数据库迁移内容或默认 5 秒健康检查。

- 主进程启动独立 Node 子进程，并等待其正常退出后才启动 gRPC/HTTP worker。
- 子进程仍调用原有数据库 loader；迁移完成或失败后关闭 Sequelize 连接，再让日志写入完成并自然退出。
- 子进程非零退出、信号退出或无法启动时，主进程启动失败，不继续启动服务。
- 初始化期间主进程收到 SIGTERM/SIGINT 时向子进程转发，并拒绝本次启动；子进程通过 IPC 断开处理主进程意外死亡。
- 只在初始化停止时设置一次 8 秒强制终止定时器，正常运行不保留该定时器或停止监听器。
- 源码运行沿用父进程的 ts-node 参数，编译后运行解析对应的 JavaScript 入口。

- 本地完整测试共 189 项：186 通过、0 失败、3 项 macOS 平台跳过；TypeScript 后端构建通过。

- 两套 Docker 容器均通过正常退出、退出码 7、1 MiB 完整日志、手动停止、5 个任务并发及秒级调度。
- 两套均通过 gRPC 暂停后健康接口返回 503、gRPC/HTTP worker 终止后恢复调度；各阶段均有实际任务成功执行。
- 两组各 121 个样本全部保留，窗口内容器及 worker 的 PID/启动时间不变，无重启或 OOM，结束时健康；空闲后再次执行任务均为退出码 0，日志完整。

## 环境与采样

沿用上一轮 Debian ARM64 镜像运行时与种子数据：Node 20.20.2、PM2 7.0.4。每容器 2 CPU、1 GiB 内存、无额外 swap；都使用 5 秒健康检查、20 次失败阈值。基线使用 `qinglong-idle:develop-optimized`，候选在其上仅替换后端源码和编译产物。

两套分别复制同一独立种子数据卷，完成同类功能与故障恢复验证后空闲。观测期间不打开面板、不执行任务、不在容器内运行额外采样命令；宿主每 5 秒通过 Docker API 读取累计 CPU、working set 和匿名内存。首尾读取进程 PSS、CPU ticks 和按信号触发的模块快照，不强制 GC。

本轮为 **10 分钟增量筛选**，不是上一轮 30 分钟实验的延长，也不是与白虎重新对比。不同轮次的 Docker VM、页面缓存及运行历史不同，不直接比较两轮 working set 绝对值，也不将节省量相加。

## 结果

| 指标 | 上一轮代码 | 独立数据库初始化 |
|---|---:|---:|
| 观测时长 | 600.02 秒 | 600.02 秒 |
| 保留样本 | 121 | 121 |
| 平均 CPU（单核） | 1.010% | 1.036% |
| 容器 working set 中位数 | 237.1 MiB | 194.9 MiB |
| 容器匿名内存中位数 | 148.4 MiB | 134.1 MiB |
| 主进程结束时 PSS | 33.9 MiB | 16.8 MiB |
| 主进程结束时 heapUsed | 16.5 MiB | 6.8 MiB |
| 主进程模块数 | 536 | 130 |

主进程 PSS 减少 **17.2 MiB**，模块数从 536 降到 130，候选主进程不再加载 Sequelize 或 SQLite 驱动。匿名内存中位数减少 **14.3 MiB**，支持本次优化有实际常驻内存收益。

working set 差值为 42.2 MiB，但该指标还包含活动文件缓存及其他计费内存，不能将全部差值归因于数据库依赖卸载。PSS、匿名内存与 working set 不是同一口径，不能相加。

本次不宣称稳定 CPU 提速；仍保留原有健康检查频率。10 分钟观测不能证明长期无泄漏，也没有测量大数据库迁移时的启动延迟或峰值内存。
