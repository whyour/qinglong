# 场景工作流编辑草稿

场景模式支持场景增删改查、搜索和分页，以及 Flowgram 原生工作流文档的编辑、保存和重新打开。保存内容包括嵌套 blocks、节点 data/meta、连线及文档其他字段，后端不重新编码为不兼容的平面节点结构。

保存前会验证节点表单；API 限制场景名称、状态、分页参数、ID、顶层节点数量和工作流文档大小。编辑场景名称时不会覆盖原有工作流或启用状态。

当前草稿没有自动执行引擎、触发器或任务调度集成。启用状态是保存的场景属性，不会触发运行。界面显示此范围，并移除了仅打印演示数据的内部 Run/Save 按钮；持久化通过编辑器弹窗的“保存工作流”完成。

后续执行引擎应另行定义节点执行协议、分支/循环语义、取消与超时、日志和权限边界，并增加真实执行测试。
