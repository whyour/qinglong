# 青龙 2.25.0-rc.0 开发候选

本候选包含 2.24.0 之后的安全、依赖、编辑器、通知及环境变量修复。主 npm 包使用 `rc` 标签发布，正式 `latest` 保持 2.24.0。

## 变更

- 应用权限、首次通知配置与任务环境变量的控制边界更严格；旧数据库中的不安全环境变量标签会在启动前修复，受保护名称不会写入任务环境，服务端错误不会向客户端泄露内部细节。
- 依赖管理页面显示已保存状态，用户可以手动复查；配置与脚本编辑器可切换自动换行。
- 通知请求和线程等待设置上限，避免无响应的通知渠道拖住任务。
- Alpine 和 Debian 镜像的内置 Python 通知依赖放在数据卷之外，挂载空 `/ql/data` 后仍能发送通知。
- 独立远程 CLI 候选 `@whyour/qinglong-cli@0.1.5-rc.1` 改善跨平台配置和 OpenAPI 操作，并移除不安全的首次通知命令。

## 测试与安装

开发镜像 `whyour/qinglong:develop`、`whyour/qinglong:debian-dev` 与主包 `@whyour/qinglong@2.25.0-rc.0` 应对应同一候选源码。主包可用 `npm install @whyour/qinglong@rc` 安装；CLI 可用 `npm install @whyour/qinglong-cli@rc` 安装。

升级前备份 `/ql/data`，在目标设备验证任务、订阅、环境变量、依赖与通知。开发候选不建议覆盖正式环境。
