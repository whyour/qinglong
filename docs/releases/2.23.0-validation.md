## 运行时风险仍待处理

Debian 候选和当前 dev 验证使用 Node 20；该发布线于 2026-04-30 结束官方维护，EOL 后不再提供官方安全修复。生产 npm 审计为零不能消除这个风险。运行时升级草稿已改为受支持的 Node 22.23.3、Python 3.11.17 和 Debian 13，全五种架构的官方 Node 发布包已核验签名、摘要与 ELF 依赖。新镜像矩阵及独立 Node 22 长跑仍待完成；上方 Node 20 长跑不会代替它。详见 [运行时支持](../development/runtime-support.md)。[Node 官方维护日程](https://github.com/nodejs/Release/blob/main/schedule.json)、[Node EOL 说明](https://nodejs.org/en/about/eol)

Python 3.10 于 2026-10-01 结束维护；它的兼容 tag 是否继续发布及如何披露风险仍待最终 review。默认 Python 3.11 仍处于安全维护期，计划到 2027-10 结束。不能把 Python 3.10 镜像构建成功写成运行时仍有安全支持。[Python 官方支持表](https://devguide.python.org/versions/)

Alpine 的运行时和构建阶段应分开记录：当前 CI 实际运行时为受支持的 Node 24；Node 18 出现在 builder。最终采用的具体运行时版本与架构、变体策略应写入发布证明。
