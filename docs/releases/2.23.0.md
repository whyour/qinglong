# 青龙 2.23.0

> 发布准备草稿，依据 `5038d2d9a046b629dfe01e8162d48fe7143f5ef4`。版本尚未发布。dev 长跑和运行时支持风险处理完成后，更新验收记录并移除本说明。

## 新增功能

- 脚本管理新增“历史版本”，查看修改前的内容、与当前保存内容对比并确认恢复。桌面采用双栏对比，手机采用行内对比。恢复前保留当前版本，可再次从历史恢复；有未保存草稿时先保存或取消。普通保存不再要求确认不可恢复覆盖。
- 新增三条脚本历史 API，沿用 scripts 权限：历史列表、版本详情、版本恢复。独立远程 CLI 0.1.2 新增 `script history-list`、`script history-detail`、`script history-restore`，有效 OpenAPI 路由由 143 条增加到 146 条。
- 定时规则明确支持 `@annually`、`@midnight`、`@minutely`，分别对应每年、每日零点、每分钟第 0 秒。

## 修复与优化

### 定时任务与执行

- Node 定时调度迁移到 `node-cron@4.6.0`，普通任务、附加规则、订阅和系统 cron 共用调度封装。保留旧表达式的标准化和日期/星期 OR 语义，交集只执行一次；语义与系统 crond 不一致的规则交给 Node 路径，避免重复执行。
- 调度替换先校验并构造全部新规则，再取消旧规则；失败时保留旧快照。大批任务恢复使用有上限的表达式缓存，注册 RPC 时限随规则数调整并封顶 120 秒。无效历史任务或订阅记录错误并隔离，不阻止其他任务恢复。
- 禁用、删除或修改定时任务后，旧规则排队等待的执行失效，不会在并发空位出现时启动。旧规则失效项不再占用新规则的单任务积压上限。已经运行的任务仍按原停止方式处理。
- 修改任务并发数时同步后端与调度进程，重启后恢复保存值；设置 `0` 恢复自动并发值。
- 修复 Shell 脚本使用 `exit`、`exec`、`set -e` 后缺失结束上报或后置钩子的问题。显式 Python/Node 解释器及普通命令保留面板和前置钩子加载的环境。
- `task -m` 超时限制覆盖 Shell、显式解释器和普通命令，到时终止所属进程组，随后升级到强制终止；普通/指定账号执行记录超时状态 `124`，完成后继续执行后置钩子。
- 优化不同工作目录和配置下的 Node 全局依赖路径缓存，减少重复查询；JS/Python 的 `QLAPI.notify` 到首次通知调用时再加载通知依赖，未发送通知的脚本避免相关初始化开销。
- 服务重启时将遗留“运行中”实例标为已停止并记录结束时间；无法恢复的旧进程退出码不再伪装成已完成状态。

### 订阅、依赖与文件管理

- 修复订阅参数的 Shell 转义和兼容性，保留自动添加/删除任务的默认行为。安全的多级、Unicode 等别名仍可使用；无效别名、SSH 主机/代理或目录逃逸会被拒绝。
- 强制删除订阅按照 URL、分支和实际执行器的目录规则清理仓库、脚本及 raw 文件，并清理关联任务；共享目录保留到最后一个订阅删除。普通删除保留文件。并发创建/修改/删除串行化，避免清理期间误删仍被使用的存储。
- 私有 SSH 订阅修改或删除后清理旧密钥配置，路径形式的别名使用隔离的 SSH 文件名。Debian 下按 OpenSSH 实际使用的用户主目录写入 Include，修复 HOME 覆盖导致私有订阅无法使用密钥的问题。
- 敏感文件名限制只作用于面板配置目录；脚本、日志目录中名为 `auth.json`、`token.json` 等的普通文件可正常访问。读取和保存仍检查路径及符号链接边界，并尊重自定义数据目录。
- 配置接口只处理配置文件；脚本对比页面改用脚本接口，修复接口范围收紧后的保存兼容性。
- 环境变量导入改为最多 5 MiB 的内存文件解析，不将上传文件名写入脚本目录；校验 JSON、变量名和非空字符串值。生成 JS 环境文件时按字符串编码值，避免值中的模板语法被当作代码执行。
- 修复 Debian/Ubuntu 镜像源更新的结果判断：成功时的 stderr 警告不再被当作失败，APT 索引获取错误不再被当作成功保存。

### 升级、API 与发布验证

- 页面升级、Shell `ql update` 和可选内部 CLI 使用一致的升级校验：先下载静态构建清单，再获取清单指定提交的源码，核对依赖锁文件和全部静态文件哈希。无效归档、路径和符号链接拒绝应用；依赖变化时在暂存目录安装。
- 系统重载保留 `.env` 和持久化数据目录，替换程序后等待健康检查；替换或启动失败时尝试恢复旧程序并重启旧服务。升级命令通过日志管道后仍保留失败退出状态，页面以真实准备结果展示成功或失败。
- 静态产物发布与版本 tag 同步，检查 Gitee Pull 镜像的实际引用是否与源提交一致；同步通知失败后仍独立验证镜像结果，避免将触发成功等同于同步完成。CLI 单独变化不再触发完整 Docker 构建，验证与发布并发组隔离。
- 数据库唯一约束冲突返回 HTTP/业务码 `409`，不暴露约束中可能包含的环境值或应用凭据。远程 CLI 区分鉴权、冲突、服务器错误和执行结果不确定的情况，保留真实 HTTP/API 错误码，不自动重放写入。
- 登录失败退避按来源 IP 隔离并设置上限，避免一个来源影响其他来源的正常登录；补全命令执行、日志路径、导出目录、gRPC 证书临时文件等输入和文件边界检查，以及中英文界面提示。
- 更新 HTTP 解析、上传、YAML、Lodash、Sequelize、gRPC、Undici、Nodemailer 等生产依赖及兼容的间接依赖补丁；移除未使用的 `http-proxy-middleware`。保留现有 SQLite N-API 包，更新预编译下载/解压安装链。

## 升级兼容性

### 运行时

源码安装要求 Node >=22，CI 验证 Node 22 和 24。默认 Debian 镜像升级为 Node 22.23.3、Python 3.11.17 和 Debian 13，保留原有五种架构；默认 Alpine 镜像使用 Python 3.11.17、Alpine 3.24 与发行版提供的 Node 24。两个原生包安装阶段也使用受支持的 Node。用户自行安装的 Node/Python/Linux 依赖应在升级后核对兼容性。Python 3.10 已结束维护，兼容镜像的新增版本策略在正式发布前单独确认。

### 脚本历史的范围与备份

历史仅在面板编辑器或调试保存覆盖已有脚本、且内容变化时记录保存前内容；每个脚本最多 20 个版本，只支持不超过 1 MiB 的 UTF-8 文本。全部压缩历史的目标上限为 32 MiB、1000 个脚本，超限时优先清理最久未更新脚本的整份历史。

上传、新增、重命名、删除、订阅更新和外部编辑不会主动留档，重命名不会自动迁移历史。历史不能恢复已删除文件，也不能代替备份。面板后续保存可以记录当时存在的外部修改内容，不能补回更早的外部版本。

超出文本范围的普通保存返回 `413`；只有返回 `historyUnavailable` 与当前哈希时，才能在明确确认后用 `skipHistory: true` 和 `expectedHash` 保存。损坏或其他容量错误不允许用这一方式绕过。恢复使用预览时的当前哈希，文件已变化返回 `409`，应重新读取和确认。普通保存没有新增全局并发编辑冲突保证。

历史位于 `<QL_DATA_DIR>/script-history`，请随完整数据目录备份。系统导出选择 `scripts` 时包含已存在的历史目录；默认导出仅覆盖基础数据库和 upload，并不自动包含所有脚本。

### 定时规则与夏令时

建议使用五字段规则，或前置秒字段的六字段规则；保留旧版简写、月份/星期名称、数字起点步长和 `L`/`#` 兼容性。`?` 只允许日期和星期字段；`H`、裸 `/N` 和未列出的宏仍会拒绝。

在有夏令时的时区，采用 node-cron 的当地时间语义：春季跳时不存在的时间跳过，秋季重复小时不再执行第二次。Asia/Shanghai 不受影响。进程内迟到触发进入既有队列，不提供停机期间的持久化补跑或分布式 exactly-once 保证。

### Shell 脚本与超时

Shell 脚本在继承前置钩子变量、数组和函数的子 Shell 中执行；脚本自己的 EXIT trap 保留。脚本修改的变量、工作目录、函数和 Shell 选项不再传回任务包装器或后置钩子。如后置钩子依赖这些修改，应改为明确传递结果。

`task -m` 支持秒、分、小时等时长，`0` 关闭超时。期限内先发 TERM，0.5 秒后发 KILL，作用于任务进程组；主动创建独立会话或进程组的程序不在此边界内。并发账号模式沿用聚合状态行为，不能将其包装器退出码当作每个账号的执行结果。现有 Shell 外层入口仍可能正常退出 `0`，应查看实际任务实例、日志和超时标识。

### 升级准备、回退与文件接口

升级前停止面板和任务，备份完整持久化数据，保留原镜像 digest、挂载、启动参数与环境配置。不要只复制正在写入的 SQLite 主文件。

`ql update false` 完成的是校验和暂存，可能在暂存目录安装依赖，之后需系统重载应用。远程系统更新 API 返回 `200` 只表示后台命令已启动，应观察更新进度及完成状态。升级失败后的自动恢复针对程序文件与服务启动，不会恢复已经改变的数据库或用户数据；完整回退仍需要升级前数据备份。

配置接口不再接受 `data/scripts/` 路径；脚本读取改用 `/scripts/detail?file=...&path=...`，保存使用脚本接口。2.22.0 已下线的三条旧文件读取接口和密码迁移回退要求继续适用，详情见 [2.22.0 升级兼容性](./2.22.0.md#升级兼容性)。

### 独立 CLI

CLI 0.1.2 要求 Node >=22.12；与面板内置 `ql` 重名，建议使用独立 npm prefix 或 `npm exec --package=@whyour/qinglong-cli -- ql ...`。脚本历史命令需要支持对应 API 的新版面板。

远程 npm CLI 只调用 API，不包含本机执行、订阅同步、升级、重载和账号恢复。内部 TypeScript 工具仍需完整 `cli/dist` 与显式 `QL_CLI_ROOT`，没有默认替代 Shell 入口。远程 `--timeout` 只限制等待 HTTP 响应，不停止服务器任务。

## 发布验收

当前候选的 Linux 回归、构建、SQLite 安装/源码编译以及四个镜像变体、24 个架构组合已通过 CI；四个 amd64 镜像另进行了断开外网的生产依赖协议验证。生产锁文件审计为 368 个依赖、各级漏洞匹配为零，没有新增忽略名单；该结果不覆盖开发依赖、用户脚本依赖或操作系统/运行时风险。

至少两小时的独立 dev 功能长跑仍在执行，新 Node 22 / Python 3.11.17 镜像的独立长跑与 Python 3.10 兼容变体的发布策略仍待完成。不能据此宣称正式发布或所有平台长期运行验收完成。依据和待完成门槛见 [发布验证记录](./2.23.0-validation.md)。
