# Internal panel integration fixture / 内部面板集成测试

Dockerfiles here are maintained only for disposable integration and compatibility tests. They are not a standalone CLI distribution and should not be published as CLI images. Users install the npm package; panel releases may embed the same artifact.

这里的 Dockerfile 仅用于临时集成和兼容性测试，不单独发布 CLI 镜像。用户通过 npm 安装，面板可集成同一产物。
